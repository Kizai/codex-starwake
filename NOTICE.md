## Separately identified visual demonstration assets

These files show AI-generated fan art of The Shorekeeper (守岸人) from Wuthering Waves (鸣潮):

- `web/assets/shorekeeper.png` — generated with the built-in OpenAI image-generation tool for this project.
- `docs/images/shorekeeper-preview.png` — screenshot of the local animation using that illustration.
- `docs/demo.mp4` — rendered animation using the same illustration.

The generation prompt is recorded in `docs/art-prompt.txt`. The artwork is a generated illustration rather than an official game asset, and is not a frame-by-frame character performance. Screenshot and video UI text was authored for this project; it is not quoted game dialogue.
